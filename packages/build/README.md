# @tsplc/build

Part of [tsPLC](https://github.com/livingforjesus/tsplc).

Builds tsPLC and raw Structured Text projects with the CODESYS compiler inside Docker. It installs pinned CODESYS libraries, compiles projects and boot applications, loads them into a runtime and applies online changes. Used by the `tsplc` CLI in `@tsplc/compiler`.

See the [documentation](https://github.com/livingforjesus/tsplc/tree/main/docs). MIT licensed.
