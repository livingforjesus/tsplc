# @tsplc/config

Part of [tsPLC](https://github.com/livingforjesus/tsplc).

The shared `tsplc.config.ts` schema: `defineConfig`, tasks, build and Docker settings, hardware devices, IO bindings, library dependencies, typegen and monitor options. Every tsPLC package and the editor read the same file.

See the [documentation](https://github.com/livingforjesus/tsplc/tree/main/docs). MIT licensed.
