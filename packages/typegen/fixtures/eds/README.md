# EDS test fixtures

Electronic Data Sheets used by the `@tsplc/typegen` and VS Code extension hardware tests. They are test-only and are not published with the package.

- `opener_sample_app.eds`: unchanged copy of the OpENer sample application EDS from https://github.com/EIPStackGroup/OpENer/blob/091e2de36f7dd640c708be6c9e40e307fe212260/data/opener_sample_app.eds (Rockwell Automation, Inc., 2009). Its BSD-style license is retained verbatim in `OpENer-license.txt`.
- `0678077312900100.eds`: vendor EDS for a Cognex DataMan barcode reader, unchanged.
- `ConveyLinx_V5_10_CODESYS.eds`: CODESYS-compatible EDS derived from the ConveyLinx V5.10 vendor EDS (Insight Automation), as noted in its header.
- `EthernetIP_CPU1_IF1__ST1.eds`: EDS generated by B&R FieldbusDESIGNER for an X67BCD321.L12 bus controller. Only the project, author and creation-date values in the leading comment header and `[File]` section were replaced; every device, assembly and connection record is unchanged.
